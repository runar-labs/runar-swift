- Macro registry integration:
  - @Encrypted macro registers:
    - Plain type decoder and wire name in `TypeNameRegistry`.
    - Encryptor in `SerializerRegistry` keyed by the plain wire name, targeting a predictable encrypted wire name (`Encrypted_<wire>`).
    - Decryptor in `SerializerRegistry` for the generated encrypted type wire name.
  - `AnyValue.serialize(context:)` now consults `SerializerRegistry`:
    - If there’s an encryptor for the plain wire, AnyValue emits `Encrypted_<wire>` with the encrypted payload deterministically (no envelope fallback on this path).
    - If not, it uses envelope encryption for the whole payload (only when context is provided).
  - `AnyValue.deserialize`:
    - Resolves via `TypeNameRegistry` only; if missing → error.
    - If decoder yields an encrypted value and a keystore is present, it decrypts to the requested plain type; otherwise returns the encrypted type if directly requested, or errors if mismatched.
